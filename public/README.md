## Notlar

- Tercihen **transparan arka planlı PNG (veya SVG)** kullanın, kartlar beyaz zemin üzerinde.
- Logolar varsayılan olarak siyah-beyaz (grayscale) görünür, üzerine gelindiğinde (hover) orijinal renklerine döner.
- Görsellerin hepsinin benzer oranlarda olması (ör. geniş/yatay) daha düzgün görünmesini sağlar.
- Daha fazla veya daha az logo eklemek/çıkarmak isterseniz, `src/components/References.jsx` dosyasındaki `brands` dizisini dosya adlarınıza göre güncelleyin.
